Lab 9: หน่วยความจำ OS (OS Memory Allocation)

เรียนรู้อัลกอริทึมการจัดสรรหน่วยความจำ First-Fit, Best-Fit, Worst-Fit และปัญหา Fragmentation

ทฤษฎีการจัดสรรหน่วยความจำ

เมื่อโปรแกรมถูกเรียกใช้งาน OS จะต้องหาพื้นที่ว่างใน RAM (Memory Allocation) อัลกอริทึมที่นิยมมี 3 แบบ:

First-Fit

ค้นหาตั้งแต่ต้น RAM และเลือก บล็อกแรก ที่มีขนาดใหญ่พอ ทำงานเร็วที่สุด แต่มักจะทิ้งเศษเล็กๆ ไว้ต้นๆ ของหน่วยความจำ

Best-Fit

ค้นหาบล็อกที่ว่างทั้งหมด และเลือกบล็อกที่ ขนาดพอดีที่สุด (เล็กที่สุดที่ใหญ่พอ) ประหยัดพื้นที่ได้ดีที่สุด แต่ต้องค้นหาทั้งหน่วยความจำและอาจเกิดเศษเล็กมากๆ ที่ใช้ทำอะไรไม่ได้

Worst-Fit

ค้นหาบล็อกที่ว่างทั้งหมด และเลือกบล็อกที่ ใหญ่ที่สุด เพื่อให้เศษที่เหลือมีขนาดใหญ่พอที่จะใช้กับโปรแกรมอื่นได้ แต่เสียพื้นที่ว่างขนาดใหญ่ไป

ปัญหา Fragmentation

  • Internal Fragmentation: การสูญเสียพื้นที่ภายในบล็อกที่จัดสรรให้ (เช่น จัดสรรแบบเพจ แล้วโปรแกรมใช้ไม่เต็มเพจ)
  • External Fragmentation: การสูญเสียพื้นที่ภายนอกบล็อก (มีพื้นที่ว่างรวมเพียงพอ แต่กระจัดกระจาย ไม่ต่อเนื่องกัน)
