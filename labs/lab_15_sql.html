Lab 15: SQL Basics

เรียนรู้พื้นฐานการจัดการฐานข้อมูลด้วยภาษา SQL (SELECT, FROM, WHERE, ORDER BY)

ทฤษฎี (Theory)

SQL (Structured Query Language) คือภาษาที่ใช้ในการจัดการและเข้าถึงข้อมูลในฐานข้อมูลเชิงสัมพันธ์ (Relational Database) คำสั่งพื้นฐานที่สำคัญมีดังนี้:

SELECT & FROM

ใช้เพื่อเลือกข้อมูลจากตาราง (Table)

SELECT column1, column2 FROM table_name; SELECT * FROM table_name; /* เลือกทุกคอลัมน์ */

WHERE

ใช้เพื่อกรองข้อมูลตามเงื่อนไขที่กำหนด

SELECT * FROM students WHERE score >= 80;

ตัวดำเนินการ: =, <>, >, <, >=, <=, AND, OR

ORDER BY

ใช้เรียงลำดับผลลัพธ์ (ASC = น้อยไปมาก, DESC = มากไปน้อย)

SELECT * FROM students ORDER BY score DESC;
