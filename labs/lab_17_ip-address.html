IP Address คืออะไร?

IP Address (Internet Protocol Address) คือหมายเลขประจำเครื่องคอมพิวเตอร์หรืออุปกรณ์ต่างๆ ที่เชื่อมต่อเข้ากับเครือข่าย เพื่อให้สามารถสื่อสารและระบุตำแหน่งกันได้ (เปรียบเสมือนบ้านเลขที่)

IPv4 (Internet Protocol version 4)

  • ขนาด 32 บิต (แบ่งเป็น 4 ชุด ชุดละ 8 บิต)
  • รูปแบบ: 192.168.1.1 (Dotted Decimal)
  • รองรับไอพีได้ประมาณ 4.3 พันล้านหมายเลข

IPv6 (Internet Protocol version 6)

  • ขนาด 128 บิต (แบ่งเป็น 8 ชุด แสดงในรูปเลขฐานสิบหก)
  • รูปแบบ: 2001:0db8:85a3:0000:0000:8a2e:0370:7334
  • ถูกสร้างขึ้นมาเพื่อแก้ปัญหา IPv4 ที่กำลังจะหมดไป

DNS (Domain Name System)

DNS เปรียบเสมือนสมุดโทรศัพท์ของอินเทอร์เน็ต ทำหน้าที่แปลงชื่อเว็บไซต์ที่มนุษย์จดจำได้ง่าย (เช่น google.com) ให้เป็น IP Address ที่คอมพิวเตอร์เข้าใจ (เช่น 142.250.190.46)
