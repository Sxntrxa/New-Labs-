ทฤษฎี IEEE 754 (32-bit)

มาตรฐาน IEEE 754 แบบ Single Precision ใช้ 32 บิตในการจัดเก็บตัวเลขทศนิยม โดยแบ่งออกเป็น 3 ส่วนหลัก:

  • Sign Bit (1 บิต): บิตเครื่องหมาย
    0 = ค่าบวก, 1 = ค่าลบ
  • Exponent (8 บิต): เลขชี้กำลังแบบ Biased (บวกด้วย 127)
    คำนวณจาก: True Exponent + 127
  • Mantissa / Fraction (23 บิต): ค่าทศนิยม (นัยสำคัญ)
    เก็บเฉพาะส่วนทศนิยมหลังจากการทำ Normalized (เลขหน้าจุดทศนิยมเป็น 1 เสมอจึงไม่ต้องเก็บ)

Value = (-1)Sign × (1.Mantissa) × 2(Exponent - 127)
