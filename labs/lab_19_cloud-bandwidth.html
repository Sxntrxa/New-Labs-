เรียนรู้เกี่ยวกับ Cloud Computing, เครือข่าย, และการคำนวณแบนด์วิดท์

แนวคิด Cloud Computing

IaaS (Infrastructure as a Service)

ให้บริการโครงสร้างพื้นฐาน เช่น Server, Storage, Network ตัวอย่าง: AWS EC2, Google Compute Engine

PaaS (Platform as a Service)

ให้บริการแพลตฟอร์มสำหรับการพัฒนาแอปพลิเคชัน ตัวอย่าง: Heroku, Google App Engine

SaaS (Software as a Service)

ให้บริการซอฟต์แวร์ผ่านอินเทอร์เน็ตพร้อมใช้งาน ตัวอย่าง: Google Workspace, Microsoft 365, Dropbox

ประเภทสื่อกลางเครือข่าย (Network Media)

Coaxial Cable

สายทองแดงแกนเดี่ยว ใช้ในระบบเคเบิลทีวีและเน็ตเวิร์กยุคเก่า

UTP (Unshielded Twisted Pair)

สายคู่ตีเกลียว ไม่มีฉนวนหุ้ม (เช่น Cat5e, Cat6) ใช้แพร่หลายใน LAN

Fiber Optic

สายใยแก้วนำแสง ส่งข้อมูลด้วยแสง ความเร็วสูง ระยะทางไกล

Wireless

เครือข่ายไร้สาย ส่งข้อมูลผ่านคลื่นวิทยุ (Wi-Fi, Bluetooth, 4G/5G)

เปรียบเทียบบริการ Cloud (Cloud Service Comparison)

IaaS

Infrastructure as a Service

ให้บริการทรัพยากรคอมพิวเตอร์พื้นฐาน เช่น เซิร์ฟเวอร์, สตอเรจ, และเครือข่าย

Examples: AWS, Google Compute Engine, Microsoft Azure
Use cases: โฮสต์เว็บไซต์, สำรองข้อมูล, จัดการเครือข่าย

PaaS

Platform as a Service

ให้บริการสภาพแวดล้อมสำหรับการพัฒนา ทดสอบ และจัดการแอปพลิเคชัน

Examples: Heroku, Google App Engine, Vercel
Use cases: พัฒนาแอปพลิเคชัน, สร้าง API

SaaS

Software as a Service

ให้บริการแอปพลิเคชันที่พร้อมใช้งานผ่านเว็บเบราว์เซอร์ ผู้ใช้ไม่ต้องติดตั้ง

Examples: Google Workspace, Office 365, Dropbox
Use cases: อีเมล, จัดการเอกสาร, ระบบ CRM

อุปกรณ์เครือข่าย (Network Hardware)

NIC (Network Interface Card)

การ์ดแลน ทำหน้าที่แปลงข้อมูลจากคอมพิวเตอร์ให้อยู่ในรูปที่ส่งผ่านสายสื่อสารได้

Hub (ฮับ)

จุดศูนย์กลางเชื่อมต่อ รับข้อมูลแล้วส่งกระจายไปทุกพอร์ต (Broadcast) ประสิทธิภาพต่ำ

Switch (สวิตช์)

ฉลาดกว่า Hub ส่งข้อมูลเฉพาะพอร์ตปลายทาง ลดการชนกันของข้อมูล

Router (เราเตอร์)

เชื่อมต่อเครือข่ายต่างชนิดกัน (เช่น LAN กับ Internet) หาเส้นทางที่ดีที่สุด

Bridge (บริดจ์)

เชื่อมต่อเครือข่าย LAN 2 วงเข้าด้วยกัน กรองข้อมูลเพื่อลดทราฟฟิก
